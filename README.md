## Applying a fix

Read the version and evidence limits first. Back up your mod and save, close the game, apply only the relevant edit to a copy, retain the mod ZIP basename and internal paths, and enable only one copy. Check the game log and the specific behavior in a copy of the save. Roll back by restoring the backed-up ZIP; restore the save backup if the test changed save data.

An upstream update requires a new comparison. A report for one local snapshot is not a universal patch. Personal tuning and retained experiments are not recommended defaults.

## Rights and contents
